档案存放要求？在自己手里怎么办？

📅 更新：2026年8月📄 人事档案政策

问题概述

事业单位录用时需要审核个人人事档案，档案的存放状态直接影响录用。很多考生毕业后档案处理不当，出现档案自持、档案拆封、档案丢失等问题，影响入职。

事业单位对档案的基本要求

事业单位招聘中，对档案的要求主要体现在以下环节：

  • 考察环节：面试通过后，招录单位会对考生进行考察，其中包括查阅人事档案
  • 档案转递：录用后，需将个人档案转递至录用单位或单位指定的人才服务机构
  • 档案完整性：档案材料应完整、真实，不得有涂改、伪造

档案应该存放在哪里？

根据干部人事档案管理规定，个人档案严禁个人自持，应存放在以下机构：

  1. 毕业学校：毕业后未就业的，学校可保留档案2年（择业期）
  2. 户籍地人才服务中心：最常见的档案存放地点，各级公共就业和人才服务机构
  3. 工作单位：有档案管理权的单位（机关、事业单位、国有企业）
  4. 就业主管部门：各级毕业生就业指导服务中心

档案在自己手里怎么办？

如果档案在个人手中，需要尽快办理存档手续：

情况一：档案未拆封、完好无损

  1. 联系户籍地（或常住地）的人才服务中心，咨询存档政策
  2. 携带身份证、毕业证、档案（密封完好）前往人才服务中心
  3. 填写存档申请表，办理存档手续
  4. 获取存档证明（存档合同或存档卡）

注意：部分人才服务中心对自持档案的接收有时间限制，一般要求毕业后2年内或择业期内，超过时间可能拒收。建议尽快办理。

情况二：档案已拆封

档案拆封后，人才服务中心通常不予接收，因为无法保证档案材料的真实性和完整性。处理方法：

  1. 联系原毕业学校，说明情况，申请重新审核密封
  2. 学校审核档案材料无误后，重新加盖密封章
  3. 密封后尽快送往人才服务中心存档
  4. 如学校不予重新密封，可联系户籍地人才服务中心协商处理方案

情况三：档案丢失

档案丢失需要补办，流程较为复杂：

  1. 联系原毕业学校档案馆，申请补办学籍档案材料
  2. 联系曾工作过的单位，补办工作经历材料（劳动合同、离职证明、考核材料等）
  3. 补办的材料需加盖原单位公章
  4. 将补办材料汇总后交人才服务中心审核存档

常见问题

Q：档案在自己手里影响报名吗？

报名和笔试阶段一般不审核档案，所以不影响报名和笔试。但在考察和录用环节需要调档，如果档案自持无法调档，会影响录用。建议在面试通过前就处理好档案问题。

Q：档案在外地人才中心，能转回黑龙江吗？

可以。凭黑龙江户籍地的人才服务中心开具的调档函，到外地人才服务中心办理档案转递手续。档案通过机要交通或EMS专递转递，不能个人携带。

Q：考上事业单位后档案怎么转？

录用单位会开具调档函，考生持调档函到档案存放机构办理转递手续。档案通过机要交通转递至录用单位，一般需要1-2周时间。

⚠️ 重要提醒：个人档案是国家机密材料，严禁个人拆封、涂改、伪造。档案自持时间越长，处理难度越大。建议毕业后及时将档案存放到人才服务中心，不要自己保管。
📌 总结提示
档案应存放在人才服务中心或有档案管理权的单位，严禁个人自持。档案在自己手里的，未拆封的尽快送人才服务中心存档；已拆封的联系原学校重新密封；丢失的联系学校和原单位补办。档案问题建议在面试前处理完毕，避免影响考察和录用。
